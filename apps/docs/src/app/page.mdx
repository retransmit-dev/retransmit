# Introduction

**Retransmit** is a developer-first messaging platform: a single API and one balance for
sending **Email, SMS, WhatsApp, OTP**, and other transactional communications.

> One API. One balance. Every message.

You don't create AWS, Twilio, or Meta accounts. You integrate Retransmit once, load credit,
and start sending — Retransmit manages the underlying providers, routing, delivery, and
infrastructure.

## What's available today

Retransmit currently supports **Email** and **SMS** through the same API key,
SDK, balance, and delivery workflow:

- Transactional email, including batches of up to 10,000 messages
- SMS with destination-aware provider routing and segment counts
- Typed Node.js SDK — [`retransmit.dev` on npm](https://www.npmjs.com/package/retransmit.dev)
- Per-message status and event history
- Signed delivery webhooks

[WhatsApp](/whatsapp) is the next channel and is not yet available in the
production API or SDK.

      │  Authorization: Bearer rt_...

## Environments

| Environment | Base URL |
| --- | --- |
| Production | `https://api.retransmit.dev` |
| Local development (this monorepo) | `http://localhost:3002` |

In local development, run the API with `pnpm dev:api` from the repository root
(it starts on port 3002). The dashboard runs on port 3001 (`pnpm dev:dashboard`).
