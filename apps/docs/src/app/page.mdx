# Introduction

Retransmit is one API and one balance for sending email, SMS, and WhatsApp messages.

You do not create AWS, Twilio, or Meta accounts. Integrate once, load credit, and send.
Retransmit handles the providers, routing, and delivery.

## What you get

- Transactional email, including batches of up to 10,000 messages
- SMS with per-country provider routing and segment counts
- WhatsApp text, template, and media messages, with replies delivered to your webhooks
- A typed Node.js SDK: [`retransmit.dev` on npm](https://www.npmjs.com/package/retransmit.dev)
- Per-message status and event history
- Signed delivery webhooks

## How it fits together

```text
Your application
      │  Authorization: Bearer rt_...
      ▼
Retransmit API  ──►  Email / SMS / WhatsApp
      │
      ▼
Retransmit infrastructure (SES, Twilio, Meta, ...)
```

## Environments

| Environment | Base URL |
| --- | --- |
| Production | `https://api.retransmit.dev` |
| Local development | `http://localhost:3002` |

Locally, run `pnpm dev:api` from the repository root. The API starts on port 3002
and the dashboard (`pnpm dev:dashboard`) on port 3001.
