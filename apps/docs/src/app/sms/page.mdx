# SMS

Retransmit launches production SMS with a deliberately narrow scope: approved
transactional programs sending to recipients in Cameroon who specifically
requested the messages. Promotional and purchased-list traffic is not accepted.

## Required flow

1. Request a program in **SMS > Programs** with the business identity, public
   opt-in page, privacy policy, SMS terms, representative content, purposes,
   and forecast volume.
2. An operator verifies the evidence and sets hard daily, monthly, and
   per-recipient caps. Sending remains blocked while the program is pending.
3. When a recipient affirmatively opts in, call
   [`POST /v1/sms/consents`](/sms/consent) with the exact disclosure they saw,
   the source, timestamp, and purposes they selected.
4. Send with the approved `from` and one matching transactional `purpose`.
5. Submit every opt-out immediately through
   [`POST /v1/sms/opt-outs`](/sms/consent). Suppression applies across the
   organization, not only one program.

```ts
const { data, error } = await retransmit.sms.send({
  from: "DISCOLAIRE",
  to: "+237670000000",
  text: "Your verification code is 482913. It expires in 10 minutes.",
  purpose: "otp",
});
```

Retransmit prefixes the message with the approved program identity and appends
the reviewed one-way opt-out and support instructions. It rejects sends outside
Cameroon, unapproved purposes, missing consent, suppressed recipients, volume
caps, and non-urgent traffic outside 08:00–20:00 Africa/Douala. The worker
checks consent and suppression again immediately before provider delivery.

## Transactional purposes

Programs may request only these purposes:

- `otp` — one-time passwords and phone verification
- `security` — account and login security alerts
- `account` — service and account notifications
- `reminder` — user-requested reminders
- `status_update` — user-requested workflow or service status

There is no marketing purpose. A purpose must be approved for the program and
selected in the recipient's consent record.

## Routing

Recipients use Cameroon E.164 numbers such as `+237670000000`. Retransmit routes
through a configured Cameroon provider; AWS traffic uses the Africa (Cape Town)
region and an AWS Protect configuration that allows Cameroon while blocking
other destinations. A pinned provider never falls back if it cannot deliver.

## Track delivery

Poll `retransmit.sms.get(id)` or [`GET /v1/sms/:id`](/sms/get) for status and
events. Subscribe to `sms.sent`, `sms.delivered`, `sms.undelivered`, and
`sms.failed` [webhooks](/webhooks) for push updates.
