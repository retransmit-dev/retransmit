# Send SMS

```http
POST /v1/sms
```

Validates and queues a transactional SMS for asynchronous delivery. Production
SMS is currently restricted to Cameroon. Every recipient must have active
consent for the approved program and declared purpose. Poll
[Get SMS](/sms/get) or subscribe to [Webhooks](/webhooks) for the outcome.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `from` | string | Yes | Sender ID of an approved Cameroon SMS program. Shared and provider-default senders are disabled. |
| `to` | string \| string[] | Yes | One recipient or up to 50 Cameroon recipients in international E.164 format. |
| `text` | string | Yes | Transactional message body, from 1 to 1,500 characters. Program identification and opt-out instructions are added automatically. |
| `purpose` | `"otp"` \| `"security"` \| `"account"` \| `"reminder"` \| `"status_update"` | Yes | Must be approved for the program and included in each recipient's active consent. |
| `provider` | `"sns"` \| `"mtn"` \| `"orange"` | No | Pins the send to one configured Cameroon carrier. Omit it to route automatically. |

## Example

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.sms.send({
  from: "DISCOLAIRE",
  to: "+237670000000",
  text: "Your verification code is 482913",
  purpose: "otp",
});
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/sms \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "DISCOLAIRE",
    "to": "+237670000000",
    "text": "Your verification code is 482913",
    "purpose": "otp"
  }'
```
</Tabs.Tab>
</Tabs>

## Response

`202 Accepted`

```json
{
  "id": "sms_xxxxxxxxxxxx",
  "status": "queued",
  "country": "CM",
  "segments": 1,
  "created_at": "2026-09-01T12:00:00.000Z"
}
```

`country` is the detected ISO 3166-1 alpha-2 destination. `segments` is the
number of billable SMS parts.

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | `invalid_json` | The request body is not valid JSON. |
| `401` | `unauthorized` | The API key is missing, invalid, or revoked. |
| `422` | `validation_error` | A field is invalid, phone numbers are malformed, or recipients span multiple countries. |
| `422` | `no_route` | No SMS provider, or not the requested one, is configured for the destination country. |
| `422` | `sender_not_allowed` | `from` is not a sender ID your organization has approved for the destination country. |
| `422` | `sms_country_not_allowed` | The destination is outside the current Cameroon launch. |
| `422` | `sms_purpose_not_allowed` | The program is not approved for the declared purpose. |
| `422` | `sms_consent_required` | A recipient has no active matching consent record. |
| `422` | `sms_recipient_suppressed` | A recipient opted out or is otherwise suppressed. |
| `422` | `sms_quiet_hours` | A non-urgent message was requested outside 08:00–20:00 Africa/Douala. |
| `429` | `sms_rate_limit` | A program, organization, or per-recipient cap was reached. |
| `500` | `internal_error` | The message could not be created. |
