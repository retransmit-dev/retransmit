# Quickstart

Send your first email, SMS, or WhatsApp message through Retransmit.

<Steps>
## Get an API key

Create an API key from the dashboard. Keys look like `rt_...` and are shown once —
store the value in your app's environment:

```sh
RETRANSMIT_API_KEY=rt_xxxxxxxxxxxxxxxx
```

## Install the SDK (optional)

For Node.js / TypeScript apps, the official
[`retransmit.dev`](https://www.npmjs.com/package/retransmit.dev) package wraps
the API with typed methods and `{ data, error }` results. It has zero
dependencies and works on Node 18+ and edge runtimes.

```sh npm2yarn
npm install retransmit.dev
```

Prefer plain HTTP? Every example below also shows the equivalent `curl` —
the API works from any language.

## Send an email

Email requires a verified sending domain. Add your domain in the dashboard and
publish the DNS records it gives you (SPF / DKIM). See [Domains](/email/domains) for
details.

You can only send from domains registered **and verified** on your account.
Sending from an unregistered domain returns `403 domain_not_found`; from an
unverified one, `403 domain_not_verified`.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
import { Retransmit } from "retransmit.dev";

const retransmit = new Retransmit(process.env.RETRANSMIT_API_KEY);

const { data, error } = await retransmit.emails.send({
  from: "Acme <hello@yourdomain.com>",
  to: "user@example.com",
  subject: "Welcome!",
  html: "<h1>Welcome!</h1>",
});

if (error) console.error(error.code, error.message);
else console.log(data.id); // em_xxxxxxxxxxxx
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/emails \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Acme <hello@yourdomain.com>",
    "to": "user@example.com",
    "subject": "Welcome!",
    "html": "<h1>Welcome!</h1>"
  }'
```
</Tabs.Tab>
</Tabs>

Response (`202 Accepted` — the email is queued and sent moments later by the
worker, which respects provider rate limits and retries transient failures):

```json
{
  "id": "em_xxxxxxxxxxxx",
  "status": "queued",
  "created_at": "2026-09-01T12:00:00.000Z"
}
```

Sending thousands at once? [Send Batch](/email/send-batch) queues up
to 10,000 emails in a single request — `retransmit.batch.send([...])` in the SDK.

## Send an SMS

SMS recipients use international E.164 format, including the leading `+` and
country code. Recipients in one request must all be in the same country.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.sms.send({
  from: "Acme",
  to: "+237670000000",
  text: "Your verification code is 482913",
});

if (error) console.error(error.code, error.message);
else console.log(data.id, data.segments); // sms_xxxxxxxxxxxx 1
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/sms \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Acme",
    "to": "+237670000000",
    "text": "Your verification code is 482913"
  }'
```
</Tabs.Tab>
</Tabs>

See [SMS](/sms) for sender IDs, routing, segment billing, and status details.

## Send a WhatsApp message

First connect your WhatsApp Business number under **WhatsApp** in the
dashboard. To start a conversation you must send an approved template; once
the recipient replies you can send free-form text for 24 hours.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.whatsapp.send({
  to: "+237670000000",
  type: "template",
  template: {
    name: "verification_code",
    language: "en_US",
    components: [{ type: "body", parameters: [{ type: "text", text: "482913" }] }],
  },
});

if (error) console.error(error.code, error.message);
else console.log(data.id); // wa_xxxxxxxxxxxx
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/whatsapp \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+237670000000",
    "type": "template",
    "template": {
      "name": "verification_code",
      "language": "en_US",
      "components": [{ "type": "body", "parameters": [{ "type": "text", "text": "482913" }] }]
    }
  }'
```
</Tabs.Tab>
</Tabs>

See [WhatsApp](/whatsapp) for templates, media, and receiving replies.

## Check delivery status

Every send returns a message `id`. Fetch it at any time from the matching
channel to see its status and event history:

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data } = await retransmit.emails.get("em_xxxxxxxxxxxx");
console.log(data?.status); // "delivered"

const { data: sms } = await retransmit.sms.get("sms_xxxxxxxxxxxx");
console.log(sms?.status); // "delivered"

const { data: wa } = await retransmit.whatsapp.get("wa_xxxxxxxxxxxx");
console.log(wa?.status); // "read"
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl https://api.retransmit.dev/v1/emails/em_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"

curl https://api.retransmit.dev/v1/sms/sms_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"

curl https://api.retransmit.dev/v1/whatsapp/wa_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"
```
</Tabs.Tab>
</Tabs>

For push-based delivery updates on every channel, and to receive WhatsApp
replies, set up [Webhooks](/webhooks).
</Steps>
