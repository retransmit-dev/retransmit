# Quickstart

Send your first email, SMS, or WhatsApp message.

<Steps>
## Get an API key

Create an API key in the dashboard. Keys start with `rt_` and are shown once.
Store it in your environment:

```sh
RETRANSMIT_API_KEY=rt_xxxxxxxxxxxxxxxx
```

## Install the SDK (optional)

The [`retransmit.dev`](https://www.npmjs.com/package/retransmit.dev) package
wraps the API with typed methods and `{ data, error }` results. It has zero
dependencies and runs on Node 18+ and edge runtimes.

```sh npm2yarn
npm install retransmit.dev
```

Every example also shows the `curl` equivalent. The API works from any language.

## Send an email

Email needs a verified sending domain. Add it in the dashboard and publish the
DNS records it gives you. See [Domains](/email/domains).

Sending from an unregistered domain returns `403 domain_not_found`. Sending
from an unverified one returns `403 domain_not_verified`.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
import { Retransmit } from "retransmit.dev";

const retransmit = new Retransmit(process.env.RETRANSMIT_API_KEY);

const { data, error } = await retransmit.emails.send({
  from: "Acme <hello@yourdomain.com>",
  to: "user@example.com",
  subject: "Welcome!",
  html: "<h1>Welcome!</h1>",
});

if (error) console.error(error.code, error.message);
else console.log(data.id); // em_xxxxxxxxxxxx
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/emails \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Acme <hello@yourdomain.com>",
    "to": "user@example.com",
    "subject": "Welcome!",
    "html": "<h1>Welcome!</h1>"
  }'
```
</Tabs.Tab>
</Tabs>

The response is `202 Accepted`. The email is queued and a worker sends it
moments later:

```json
{
  "id": "em_xxxxxxxxxxxx",
  "status": "queued",
  "created_at": "2026-09-01T12:00:00.000Z"
}
```

For thousands of emails, use [Send Batch](/email/send-batch)
(`retransmit.batch.send([...])` in the SDK). It takes up to 10,000 per request.

## Send an SMS

Recipients use international E.164 format with the leading `+` and country
code. All recipients in one request must be in the same country.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.sms.send({
  from: "Acme",
  to: "+237670000000",
  text: "Your verification code is 482913",
});

if (error) console.error(error.code, error.message);
else console.log(data.id, data.segments); // sms_xxxxxxxxxxxx 1
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/sms \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Acme",
    "to": "+237670000000",
    "text": "Your verification code is 482913"
  }'
```
</Tabs.Tab>
</Tabs>

See [SMS](/sms) for sender IDs, routing, segments, and statuses.

## Send a WhatsApp message

Connect your WhatsApp Business number under **WhatsApp** in the dashboard. A
conversation must start with an approved template. Once the recipient replies,
you can send free-form text for 24 hours.

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.whatsapp.send({
  to: "+237670000000",
  type: "template",
  template: {
    name: "verification_code",
    language: "en_US",
    components: [{ type: "body", parameters: [{ type: "text", text: "482913" }] }],
  },
});

if (error) console.error(error.code, error.message);
else console.log(data.id); // wa_xxxxxxxxxxxx
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/whatsapp \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+237670000000",
    "type": "template",
    "template": {
      "name": "verification_code",
      "language": "en_US",
      "components": [{ "type": "body", "parameters": [{ "type": "text", "text": "482913" }] }]
    }
  }'
```
</Tabs.Tab>
</Tabs>

See [WhatsApp](/whatsapp) for templates, media, and replies.

## Check delivery status

Every send returns an `id`. Fetch it any time for the status and event history:

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data } = await retransmit.emails.get("em_xxxxxxxxxxxx");
console.log(data?.status); // "delivered"

const { data: sms } = await retransmit.sms.get("sms_xxxxxxxxxxxx");
console.log(sms?.status); // "delivered"

const { data: wa } = await retransmit.whatsapp.get("wa_xxxxxxxxxxxx");
console.log(wa?.status); // "read"
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl https://api.retransmit.dev/v1/emails/em_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"

curl https://api.retransmit.dev/v1/sms/sms_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"

curl https://api.retransmit.dev/v1/whatsapp/wa_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"
```
</Tabs.Tab>
</Tabs>

For push updates and WhatsApp replies, set up [Webhooks](/webhooks).
</Steps>
