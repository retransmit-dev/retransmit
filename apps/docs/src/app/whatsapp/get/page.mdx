# Get WhatsApp

```http
GET /v1/whatsapp/:id
```

Retrieves a previously queued WhatsApp message, including its current
delivery status and event history.

## Example

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.whatsapp.get("wa_xxxxxxxxxxxx");
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl https://api.retransmit.dev/v1/whatsapp/wa_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"
```
</Tabs.Tab>
</Tabs>

```json
  "from": "+237650000000",
  "to": "+237670000000",
  "country": "CM",
  "type": "text",
  "text": "Your verification code is 482913",
  "preview_url": false,
  "template": null,
  "media": null,
  "provider": "meta",
  "provider_message_id": "wamid.HBgMMjM3Njc...",
  "status": "read",
  "error": null,
  "created_at": "2026-09-01T12:00:00.000Z",
  "last_event_at": "2026-09-01T12:00:09.000Z",
  "events": [
    { "type": "whatsapp.sent", "created_at": "2026-09-01T12:00:01.000Z" },
    { "type": "whatsapp.delivered", "created_at": "2026-09-01T12:00:03.000Z" },
    { "type": "whatsapp.read", "created_at": "2026-09-01T12:00:09.000Z" }
  ]

```

`provider_message_id` is the WhatsApp message id. Replies that quote this
message reference it, and it is what you see in `whatsapp.received` webhooks.

## WhatsApp statuses

| Status | Meaning |
| --- | --- |
| `queued` | Accepted and waiting for a worker. |
| `sent` | Accepted by WhatsApp. |
| `delivered` | Delivered to the recipient's device. |
| `read` | The recipient opened the message. Only reported when they share read receipts. |
| `failed` | Sending failed permanently, or WhatsApp could not deliver it. `error` explains why. |

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `401` | `unauthorized` | The API key is missing, invalid, or revoked. |
| `404` | `not_found` | No WhatsApp message with this ID exists on your account. |
| `500` | `internal_error` | The request failed unexpectedly. |
