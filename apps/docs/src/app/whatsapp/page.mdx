# WhatsApp

Send WhatsApp messages through the same Retransmit API key and SDK you use for
email and SMS. Messages go out from your own WhatsApp Business number, so
recipients see your business name and replies come straight back to you.

## Connect a number

Open **WhatsApp** in the dashboard and click **Connect a number**. Meta's
signup dialog walks you through logging in with Facebook, picking or creating
your business, and verifying a phone number you own by SMS or voice call. No
Meta developer account or code is needed; Retransmit's app handles the
integration.

A number can only be attached to one WhatsApp app at a time. If it is
currently used in the WhatsApp or WhatsApp Business app, remove it there
first. Most organizations connect one number; connect several if you need
separate identities and pass `from` when sending.

## Send a message

```ts
import { Retransmit } from "retransmit.dev";

const retransmit = new Retransmit(process.env.RETRANSMIT_API_KEY);

const { data, error } = await retransmit.whatsapp.send({
  to: "+237670000000",
  text: "Your order is ready for pickup.",
});
```

Recipients must be in international E.164 format. Each request targets one
recipient, and the response carries the message `id` you use to track it.

## Templates and the 24-hour window

WhatsApp only lets a business start a conversation with an approved
**template**. Once the recipient replies, a 24-hour customer service window
opens and you can send free-form `text`, `image`, and `document` messages
until it closes.

```ts
await retransmit.whatsapp.send({
  to: "+237670000000",
  type: "template",
  template: {
    name: "order_ready",
    language: "en_US",
    components: [
      { type: "body", parameters: [{ type: "text", text: "#48213" }] },
    ],
  },
});
```

Templates are created and approved in WhatsApp Manager on the business you
connected. The `name` and `language` you pass must match the approved
template exactly.

A free-form message sent outside the window is accepted by the API but comes
back as `failed` with the provider's error once the worker sends it.

## Media

Images and documents are sent by public link. Retransmit passes the link to
WhatsApp, which downloads it at send time, so the URL must be reachable
without authentication.

```ts
await retransmit.whatsapp.send({
  to: "+237670000000",
  type: "document",
  document: {
    link: "https://files.example.com/invoices/48213.pdf",
    filename: "invoice-48213.pdf",
    caption: "Your invoice",
  },
});
```

## Track delivery

Poll `retransmit.whatsapp.get(id)` or [`GET /v1/whatsapp/:id`](/whatsapp/get)
for the current status and event history. For push updates, subscribe to
`whatsapp.sent`, `whatsapp.delivered`, `whatsapp.read`, and `whatsapp.failed`
[webhooks](/webhooks).

## Replies

WhatsApp is a two-way channel. When a recipient answers, Retransmit delivers
the message to your webhook endpoints as `whatsapp.received`. See
[Receive messages](/whatsapp/receive).

See [Send WhatsApp](/whatsapp/send) for the complete request contract.
