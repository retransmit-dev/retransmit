# WhatsApp API Reference

> [!WARNING]
>
> This is a preview of the planned SDK shape, not a production API. WhatsApp
> methods are not exported by the current `retransmit.dev` SDK release.

WhatsApp will use a dedicated `retransmit.whatsapp` namespace, consistent with
`retransmit.emails` and `retransmit.sms`.

```ts
// Preview only — this method is not available yet.
await retransmit.whatsapp.send({
  // Message fields will be documented before launch.
});
```

The endpoint, supported message types, and final request fields will be
documented here when the production contract is ready.
