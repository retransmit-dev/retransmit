# Email

Send transactional or marketing email through Retransmit with verified sending
domains, asynchronous delivery, batch sending, and delivery tracking.

## Get started

- [Send an email](/email/send) — queue a transactional or marketing email.
- [Send a batch](/email/send-batch) — queue up to 10,000 emails at once.
- [Get an email](/email/get) — inspect its status and event history.
- [Get a batch](/email/get-batch) — track aggregate batch progress.

## Configure email

- [Domains](/email/domains) — register and verify a sending domain.
- [Marketing Email](/email/marketing-email) — add unsubscribe handling and
  suppression to campaigns.

For authentication, response formats, and shared API behavior, see the
[API Reference](/api-reference).
