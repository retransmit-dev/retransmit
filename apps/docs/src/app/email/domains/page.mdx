# Domains

Retransmit only sends email from domains that are registered on your account
and verified.

## Adding a domain

1. Open **Domains** in the dashboard.
2. Add your domain, e.g. `yourdomain.com`.
3. Publish the DNS records shown (SPF / DKIM) at your DNS provider.
4. Wait for verification to complete.

## Domain statuses

| Status | Meaning |
| --- | --- |
| `pending` | DNS records not yet detected. Propagation can take a few hours. |
| `verified` | Ready to send. |
| `failed` | Verification failed. Re-check the DNS records. |
| `temporary_failure` | Verification hit a transient issue and will be retried. |

## Sending from an unready domain

`POST /v1/emails` rejects the request before anything is sent:

| Condition | Response |
| --- | --- |
| The `from` domain is not on your account | `403 domain_not_found` |
| The domain exists but is not `verified` | `403 domain_not_verified`. The message includes the current status. |

```json
{
  "error": {
    "code": "domain_not_verified",
    "message": "The domain `yourdomain.com` is not verified yet (status: pending)."
  }
}
```

> [!TIP]
>
> `from` accepts a bare address (`hello@yourdomain.com`) or a display name
> form (`Acme <hello@yourdomain.com>`). The domain is taken from the address.
