# Get SMS

```http
GET /v1/sms/:id
```

Retrieves a previously queued SMS, including its current delivery status and
event history.

## Example

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.sms.get("sms_xxxxxxxxxxxx");
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl https://api.retransmit.dev/v1/sms/sms_xxxxxxxxxxxx \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY"
```
</Tabs.Tab>
</Tabs>

## SMS statuses

| Status | Meaning |
| --- | --- |
| `queued` | Accepted and waiting for a worker. |
| `sent` | Handed to the upstream provider. |
| `delivered` | The carrier confirmed delivery. |
| `undelivered` | The carrier could not deliver the message. |
| `expired` | The carrier's delivery window expired. |
| `rejected` | The carrier rejected the message. |
| `failed` | Sending failed permanently after retries or no route was available. |

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `401` | `unauthorized` | The API key is missing, invalid, or revoked. |
| `404` | `not_found` | No SMS with this ID exists on your account. |
| `500` | `internal_error` | The request failed unexpectedly. |
