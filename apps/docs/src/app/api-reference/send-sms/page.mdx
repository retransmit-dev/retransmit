# Send SMS

```http
POST /v1/sms
```

Validates and queues an SMS for asynchronous delivery. Retransmit normalizes
the recipient numbers, detects their destination country, and selects an
available provider. Poll [Get SMS](/api-reference/get-sms) or subscribe to
[Webhooks](/webhooks) for the outcome.

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `from` | string | No | Sender ID shown on the recipient's device. Up to 11 letters, digits, spaces, hyphens, or underscores. Defaults to the provider's configured sender. |
| `to` | string \| string[] | Yes | One recipient or up to 50 in international E.164 format. All recipients must be in the same country. |
| `text` | string | Yes | Message body, from 1 to 1,600 characters. |

## Example

<Tabs items={["Node.js", "cURL"]}>
<Tabs.Tab>
```ts
const { data, error } = await retransmit.sms.send({
  from: "Acme",
  to: "+237670000000",
  text: "Your verification code is 482913",
});
```
</Tabs.Tab>
<Tabs.Tab>
```sh
curl -X POST https://api.retransmit.dev/v1/sms \
  -H "Authorization: Bearer $RETRANSMIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Acme",
    "to": "+237670000000",
    "text": "Your verification code is 482913"
  }'
```
</Tabs.Tab>
</Tabs>

## Response

`202 Accepted`

```json
{
  "id": "sms_xxxxxxxxxxxx",
  "status": "queued",
  "country": "CM",
  "segments": 1,
  "created_at": "2026-09-01T12:00:00.000Z"
}
```

`country` is the detected ISO 3166-1 alpha-2 destination. `segments` is the
number of billable SMS parts.

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | `invalid_json` | The request body is not valid JSON. |
| `401` | `unauthorized` | The API key is missing, invalid, or revoked. |
| `422` | `validation_error` | A field is invalid, phone numbers are malformed, or recipients span multiple countries. |
| `422` | `no_route` | No SMS provider is configured for the destination country. |
| `500` | `internal_error` | The message could not be created. |
